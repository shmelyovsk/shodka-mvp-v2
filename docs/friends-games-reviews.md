# Друзья, контакты, спорт и игры, отзывы

## Как обновить

1. Распакуйте архив и откройте папку shodka.
2. В GitHub shodka-mvp-v2 → Add file → Upload files перетащите содержимое shodka (не внешнюю папку).
3. Создайте ветку friends-and-games и pull request. Объедините после проверки.
4. В Render сначала обновите API shodka-mvp-v2: Manual Deploy → Deploy latest commit. Команда сборки остаётся npm ci --include=dev && npm run build --workspace @shodka/server.
5. После Live обновите frontend shodka-mvp-v2-1 тем же способом.
6. Переменные, токены, DATABASE_URL, Neon менять не нужно. Новые поля и массивы необязательные; старые данные остаются. Отдельной миграции таблиц нет: MVP хранится в versioned JSONB.
7. Полностью закройте и заново откройте мини-приложение. В профиле выберите ник и при желании разрешите обмен Telegram-контактом.
8. В боте отправьте /support. Команда регистрируется сервером при запуске polling. Существующее меню клиента может обновляться с задержкой.

## Новое

### Ники и друзья

Ник СХОДКИ не связан с Telegram username. 3–24 символа: латинская буква в начале, далее латиница, цифры, _. Уникальность проверяется без учёта регистра. Ник выбирается в личном кабинете; он нужен для отправки запросов в друзья.

Кнопка «Друзья и запросы» в профиле открывает поиск по нику, входящие и отправленные запросы, список друзей. Запрос принимает только получатель. Отправитель может отменить запрос, получатель — отклонить, обе стороны — удалить дружбу. В каталоге есть «Организуют друзья». В профиле друга видны его предстоящие сходки.

Уведомлений бота о запросах в друзья в этой версии нет — запросы видны в разделе Друзья.

### Контакты

Telegram username хранится отдельно от ника. При наличии username в подписанных данных Telegram он подставляется в свой профиль; пользователь может исправить его. Для MAX контакт Telegram указывается вручную, если у человека он есть.

По умолчанию контакт закрыт. Передача включается владельцем в профиле. После согласия контакт видят подтверждённые друзья, а также организатор и одобренный участник одной неотменённой сходки. Остальные участники встречи автоматически контакты друг друга не получают. До одобрения контакты по заявке закрыты.

Отмена дружбы закрывает доступ по дружбе; общая подтверждённая встреча может оставаться другим основанием доступа. Снятие галочки «Показывать контакт» закрывает его всем, кроме самого владельца. Уже скопированную информацию отозвать невозможно.

Ручной контакт является данными, указанными пользователем, а не отдельной проверкой личности.

### Публичные профили

Плашки участников, имя/фото организатора, карточка заявителя открывают профиль. Там — имя, ник, возраст, фото, описание, район, интересы, уровень, реальные отзывы и организуемые встречи. Приватные настройки уведомлений и Telegram контакт без соответствующих прав не возвращаются API.

### Встречи и игры

Категории: Спорт и Компьютерные игры. Списки расширены, «Другое» открывает поле собственного названия. Доступны личная встреча и онлайн-формат. Для игр можно указать платформу, сервер или уровень текстом.

Онлайн-встреча не требует физического района/адреса. Необязательная HTTPS-ссылка подключения скрыта в публичном каталоге и списке встреч организатора; её видят организатор и принятые участники в деталях/своих встречах. Само по себе наличие дружбы не открывает ссылку комнаты.

На карточках явно указано «Уровень: …» и «Возраст: …». В шапке — Москва · 16+.

### Поддержка

Блок поддержки удалён из кабинета. В Telegram/MAX добавлена /support. Команда объясняет добровольную поддержку. Платежи и ссылки пока не подключены: сначала нужно выбрать подходящий механизм и проверить его условия.

### Рейтинг и отзывы

Показанный рейтинг теперь считается из реальных отзывов, старые демонстрационные значения не используются. Рядом отображается количество отзывов.

Оставить отзыв можно через 24 часа после начала неотменённой встречи, если автор и оцениваемый были её организатором или одобренными участниками. Нельзя оценивать себя, постороннего, будущую/отменённую встречу либо повторно оценивать одного человека за ту же встречу. Нужно подтвердить «Мы встретились». Оценка 1–5, комментарий до 500 символов.

Это самоподтверждение участника, а не независимая проверка посещения. Рейтинг не следует считать гарантией безопасности или личности. Автоматических штрафов за неявку нет.

На отзыв можно пожаловаться, указав причину. Повторная жалоба того же человека на тот же отзыв блокируется. Жалобы сохраняются в reviewReports в JSONB PostgreSQL; отдельной панели модерации и автоматической рассылки модераторам пока нет. Команда проекта должна разбирать их вручную. Жалоба сама по себе не удаляет отзыв и не меняет среднюю оценку; владелец профиля не может удалять чужие отзывы через API.

## Проверки после установки

- Два аккаунта выбирают разные ники. Занятый ник должен отклоняться.
- Найти друга, отправить запрос, принять со второго аккаунта, проверить список и фильтр каталога.
- Разрешить контакты в обоих профилях, проверить их до/после принятия дружбы или заявки. Удалить друга и проверить отзыв доступа при отсутствии другой общей встречи.
- Создать онлайн-встречу с «Другой» игрой. У непринятого пользователя ссылка комнаты скрыта, после принятия видна.
- Открыть профили из карточки сходки, списка участников и входящей заявки.
- Для отзыва открыть профиль участника общей встречи через сутки после её начала. Проверить появление среднего рейтинга и число отзывов.
- Проверить /support, компактную шапку и понятные подписи.

## Выполненная автоматическая проверка

TypeScript frontend/backend, Vite production build, прежние проверки авторизации/адресов/архива, сохранение PostgreSQL после перезапуска, сохранение новых друзей/отзывов. Интеграционные проверки: уникальность ников без регистра, поиск, права принятия/удаления дружбы, контакты до/после одобрения и отзыва согласия, фильтр друзей, скрытие онлайн-ссылок, право/срок/дубликаты отзывов, средний рейтинг и жалобы.

Сетевые API Telegram/MAX в автоматических тестах заменены заглушками; тесты не отправляют реальные сообщения и не касаются рабочей Neon. Внешний вид и реальный обмен между двумя устройствами нужно проверить после развёртывания.
