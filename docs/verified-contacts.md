# Подтверждённые Telegram-контакты — contacts-v4

## Изменения

Переключатель показа контактов убран. Telegram-контакт в профиле доступен только для чтения. Ник СХОДКИ остаётся редактируемым.

Telegram-контакт поступает только из подписанных данных Telegram или из подтверждённой привязки через Telegram-бота. Запросы с ручным изменением telegramContact, shareContact или telegramOwnerId отклоняются сервером. Старые вручную введённые контакты не считаются подтверждёнными и не показываются другим.

После одобрения заявки контакт открывается взаимно организатору и участнику. Два рядовых участника не получают контакты друг друга только из-за участия в одной встрече. Принятые друзья также видят подтверждённые контакты друг друга. Посторонние и ожидающие одобрения контактов не видят. Отмена встречи, отклонение ранее одобренной заявки и удаление дружбы закрывают соответствующее основание доступа. Если осталась другая одобренная общая встреча или дружба, доступ может сохраняться.

Перед созданием встречи и подачей заявки нужен подтверждённый Telegram-контакт. Для одобрения заявки он нужен и организатору, и участнику. Если ник удалён в Telegram, при следующем получении актуальных данных контакт очищается.

## Если пользователь входит через Telegram

Установите @username в настройках Telegram. Полностью закройте мини-приложение и откройте заново через бота. Поле Telegram-контакта обновится из данных нового входа. Если меняете имя пользователя в Telegram, нужно заново открыть мини-приложение; текущая сессия может содержать старые подписанные данные.

## Если пользователь входит через MAX

MAX не передаёт Telegram-ник. В профиле есть «Привязать Telegram»:
1. Сначала заполните возраст в профиле, если он ещё не заполнен.
2. Нажмите «Привязать Telegram».
3. Нажмите появившуюся ссылку «Открыть Telegram для подтверждения».
4. В Telegram нажмите «Запустить» в нашем боте. Ник будет получен из Telegram, вручную вводить его не нужно.
5. Вернитесь в MAX и нажмите «Обновить контакт».

Ссылка одноразовая, действует 10 минут, при создании новой предыдущая становится недействительной. Если ника нет, сначала установите его в Telegram и повторите переход. Не передавайте свою ссылку привязки другим людям. Эта привязка подтверждает контакт; она не объединяет профили, друзей и встречи MAX и Telegram.

Если позже измените или удалите ник в Telegram, напишите нашему Telegram-боту /start, а затем нажмите «Обновить контакт» в MAX. Это передаст актуальный контакт связанным профилям.

## Выкладка

1. Скачайте shodka-verified-contacts.zip и распакуйте.
2. GitHub → shmelyovsk/shodka-mvp-v2 → Code, ветка main → Add file → Upload files.
3. Загрузите всё содержимое папки shodka: apps, tests, docs и package.json. Внешнюю папку shodka не загружайте.
4. Создайте ветку verified-contacts, сохраните изменения.
5. Create pull request → Merge pull request → Confirm merge.
6. В Render откройте shodka-mvp-v2, сервер без -1.
7. Manual Deploy → Deploy latest commit, если автоматически ещё не запустился. Дождитесь Live.
8. Откройте https://shodka-mvp-v2.onrender.com/health. Нужны release: "contacts-v4", apiVersion: 4, storage: "postgres".
9. Затем обновите shodka-mvp-v2-1 через Deploy latest commit и дождитесь Live.
10. Полностью переоткройте мини-приложение.

API_VERSION остаётся 4, но новый клиент дополнительно проверяет наличие verifiedContacts в /api/capabilities. Если сервер ещё старый, приложение попросит дождаться обновления.

Токены, DATABASE_URL и MODERATOR_USER_IDS менять не нужно. Новых пакетов или миграции таблиц нет. Архив также включает ранее подготовленные помощь и предложения и разные значки навигации, поэтому их можно выложить вместе.

После обновления каждому пользователю Telegram нужно открыть приложение заново, чтобы заменить старый вручную указанный контакт на настоящий. Для старых заявок одобрение потребует актуальных контактов обеих сторон.

## Проверка

1. Профиль: контакта нельзя редактировать, галочки показа нет; ник СХОДКИ по-прежнему меняется.
2. С другого аккаунта до одобрения контакт скрыт.
3. После одобрения организатор и участник видят контакты друг друга в профилях.
4. Посторонний пользователь контакта не видит.
5. После принятия дружбы контакты открываются без переключателя.
6. Попробуйте пользователя без username: создание встречи/подача заявки должны объяснить, как заполнить контакт.
7. Измените username в Telegram и заново откройте приложение: поле должно обновиться.
8. Проверьте /help, /idea и обращения модератора, если ещё не проверяли предыдущий выпуск.

Сценарии обращений и команды бота также прошли. Telegram заменён имитацией: реальную доставку, открытие ссылки между мессенджерами и вид на телефоне проверьте после выкладки.
