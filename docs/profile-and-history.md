# Обновление: личный кабинет, навигация и история

## Установка в существующий проект

В архиве лежит папка shodka с изменёнными файлами. Через GitHub Upload files загрузите содержимое shodka в корень shodka-mvp-v2 (не саму внешнюю папку). Создайте ветку profile-and-history, pull request и объедините после проверки.

Обновите оба сервиса Render:
- API shodka-mvp-v2: npm ci --include=dev && npm run build --workspace @shodka/server
- Frontend shodka-mvp-v2-1: сохраните действующую команду сборки и VITE_API_URL, запустите новое развёртывание.

DATABASE_URL, токены, настройки Neon менять не нужно. Схема PostgreSQL и существующие записи сохраняются. Новые поля профиля необязательные. Сначала обновляйте сервер, затем frontend. В Telegram/MAX закройте и заново откройте мини-приложение.

## Новое поведение

- Каталог показывается сразу. Возраст заполняется в личном кабинете и обязателен перед созданием сходки/заявкой. Проверка 16–100 лет сохраняется на сервере.
- Аватар сверху справа открывает профиль. Поля: имя, возраст, район/метро, о себе, виды спорта, уровень, уведомления.
- При наличии photo_url в подписанных данных Telegram/MAX используется фото платформы. Пользователь может загрузить JPG/PNG/WebP, изображение обрезается по центру и уменьшается до 256×256 перед сохранением. Собственное фото не перезаписывается при следующем входе.
- Загруженные миниатюры пока хранятся в PostgreSQL вместе с профилем, без отдельного файлового сервиса. При росте проекта потребуется объектное хранилище.
- Настройка уведомлений отключает сообщения о заявках/изменениях встречи; ответы на команды бота остаются. Фоновых напоминаний пока нет.
- Шапка главной: Москва и аватар. Повторное крупное название убрано. Внизу — единые SVG-иконки с лаймовым выделением активного раздела.
- Продолжительность убрана из карточек и подробностей. Старое поле в данных сохранено для совместимости; новые встречи не получают выдуманное время окончания.
- В общей ленте сходка видна до начала. В «Моих» есть Предстоящие, Прошедшие и Отменённые. Начавшиеся сегодня остаются в Предстоящих с пометкой «Уже началась» до полуночи по Москве; затем переходят в Прошедшие. Записи не удаляются. Это история запланированных встреч, не подтверждение посещения.
- Новое приветствие Telegram без перечисления мессенджеров и без 16+. В MAX из приветствия убрана строка про 16+. Возрастное правило сервиса сохранено.
- В профиле есть «Поддержать СХОДКУ» с объяснением добровольной поддержки. Платёж не подключён: ссылку/механизм выберем отдельно после проверки условий платформ. Никаких платных преимуществ нет.

## Проверка после развёртывания

1. Открыть каталог с новым аккаунтом, не заполняя возраст. Перейти в создание — приложение должно предложить профиль.
2. В профиле заполнить поля, загрузить фото, сохранить, закрыть и открыть приложение. Убедиться, что всё сохранилось.
3. Создать встречу, подать заявку другим аккаунтом, принять её. Проверить отображение фото и скрытие адреса до подтверждения.
4. Во вкладке Мои открыть историю и отменённые встречи. У прошедшей встречи не должно быть работающей кнопки заявки.
5. Отключить уведомления у участника, изменить его заявку: сообщение не должно приходить. Затем включить и повторить.
6. Отправить /start боту — проверить новое приветствие.

## Выполненные проверки

TypeScript frontend/backend и Vite production build проходят. API-тесты проверяют сохранение полей, переключение фото платформы/собственного фото, валидацию и атомарность профиля, возрастные ограничения, предпочтения уведомлений, общие сходки MAX ↔ Telegram, приватность адреса и доступ к истории. Отдельно проверены границы архива по Москве и прежние PostgreSQL-тесты сохранности.

Автоматический просмотр интерфейса в браузере в этой среде оказался недоступен; визуальную проверку на реальном телефоне нужно выполнить после развёртывания.
